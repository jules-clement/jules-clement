# Hi, I’m Jules Clement

I’m a technical project management specialist focused on improving
the tools and integrations that help technical teams plan,
coordinate, and deliver software.

My engineering interests center on integration reliability,
workflow automation, CI/CD, and dependable project information.

## Areas of focus

- Connecting project-management systems and developer tools.
- Automating repetitive workflows and synchronizing issues.
- Improving CI/CD workflows and release coordination.
- Improving data accuracy, reporting, and delivery visibility.
- Strengthening integrations through regression tests and
  practical documentation.

## Initial open-source work

I’m starting with Jira and Confluence integration reliability,
with a broader interest in workflow automation, CI/CD,
accurate project information, and developer tooling.

## How I work

I start with a reproducible problem, keep changes focused, and
check that fixes preserve existing behavior. I document what was
tested and what remains uncertain.

I direct the work, review and approve submissions, and take
responsibility for the changes I submit. I follow each project’s
contribution guidelines and respond constructively to review.
